<b>How to start:</b><br>
because this is a single HTML file solution, the CORS prevents external data to be loaded. So start the browser with "--disable-web-security" command line argument and load the HTML solution file <i>index.html</i>.<br>
<p><b>Example:</b> <i>chromium --disable-web-security --user-data-dir=./chromi index.html</i></p>
<p>Don't use the same browser for other purposes because of the removed Cross-Origin protection!</p>
